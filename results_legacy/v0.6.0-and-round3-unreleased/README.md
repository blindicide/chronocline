# Legacy v0.6.0 and Round-3-unreleased campaign artifacts

This directory preserves the former `publication_results` tree byte-for-byte as
historical evidence. It is deliberately excluded from current publication
validation and must not be edited or relabelled as v0.7.0 output.

The artifacts predate the Round-4 corrections for interval-tail tolerance,
nearest-bin construction, complete work-unit accounting, stateful batching
semantics, Miller--Madow correction, phase interpretation, and strict source
provenance. They therefore remain useful for audit/reproduction of the former
implementation, but are not evidence of current scientific acceptance.
